# Support

- Usage questions and design discussions: [GitHub Discussions](https://github.com/icenfly/real-agentic-workflows/discussions)
- Reproducible bugs and feature requests: [GitHub Issues](https://github.com/icenfly/real-agentic-workflows/issues)
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), never a public issue

When asking for help, include the REAL version, Python version, operating system, the smallest redacted workflow that reproduces the problem, the command used, and the structured error output.
